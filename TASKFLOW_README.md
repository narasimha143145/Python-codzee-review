#TaskFlow — Task Management System

TaskFlow is a Python project demonstrating object-oriented programming, input validation, task management, and error handling.

## Features

- Create tasks with unique IDs
- Validate task titles and priorities
- Track task completion status
- Filter tasks by completion status and priority
- Delete tasks safely
- Record task creation timestamps

## Technology Stack

- Python 3
- Object-oriented programming (OOP)
- Python standard library

## Getting Started

### Prerequisites

Make sure Python 3 is installed.

### Run the application

bash
python app.py


## Current Limitations

Tasks are stored in memory and are lost when the application exits.
